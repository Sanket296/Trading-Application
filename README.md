# Tradewave

** It is a full-Stack Trading & portfolio Management web application that provides an intuitive interface for monitoring markets, managing a trading portfolio, and placing live orders by a backend API and dashboard. It demonstrates end to end product thinking, real time UI updates, secure user management, and deployment readiness.

**Key features

Segregated frontend services: Public landing pages and authenticated dashboard (security isolation).
Authentication and session handling for dashboard access.
Dynamic charts for portfolio breakdown and holdings analysis.
Backend REST APIs for data and order management.
Modular React routing for dashboard views.
Responsive UI using Material UI, Bootstrap and custom CSS.


**Tech stack

Frontend: React.js, HTML5, CSS, Bootstrap, Material UI, Chart.js.
Backend: Node.js / Express  or API endpoints to serve simulated market data.
Database: MongoDB.
